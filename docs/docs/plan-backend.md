# Plan inicial del backend de MicroFlux

## Estado actual

El proyecto MicroFlux actualmente se encuentra en fase de planificación técnica y preparación del entorno colaborativo. Todavía no se ha iniciado la implementación funcional del sistema.

## Objetivo de esta etapa

Preparar la base del repositorio backend para que el equipo pueda comenzar el desarrollo de forma organizada en una fase posterior.

## Tecnologías proyectadas

- Node.js: entorno de ejecución para el backend.
- Fastify: framework que se usará para construir la API.
- PostgreSQL: base de datos relacional del sistema.
- Prisma: ORM para conectar el backend con la base de datos.
- JWT: manejo futuro de autenticación mediante tokens.
- bcrypt: protección futura de contraseñas mediante hashing.
- Zod: validación futura de datos recibidos por la API.
- Swagger UI: documentación futura de los endpoints.

## Alcance de esta tarea

Esta tarea no implementa código funcional. Solo deja documentada la intención técnica del backend y prepara el repositorio para el desarrollo futuro.
